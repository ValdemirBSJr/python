# Automatizador de README e Subida para o GitHub
## Descrição curta
Este projeto utiliza Python e IA (Groq) para automatizar a criação de arquivos README.md e a subida de projetos para o GitHub.

## Principais Conceitos
* Automatização da criação de arquivos README.md utilizando IA (Groq)
* Subida de projetos para o GitHub utilizando o GitHub CLI
* Utilização de Python 3.11 ou superior
* Instalação do git e do GitHub CLI (gh) para funcionalidade completa

## Como usar
1. **Instalar dependências**:
   - Instalar Python 3.11 ou superior
   - Instalar o git e o GitHub CLI (gh) seguindo as instruções abaixo:
     - No Windows: instalar o git via [https://git-scm.com/downloads](https://git-scm.com/downloads) e o GitHub CLI via [https://cli.github.com/](https://cli.github.com/)
     - No Linux (Arch): `sudo pacman -S git` e `sudo pacman -S github-cli`
2. **Configurar o gh**:
   - Executar `gh auth login` e seguir as instruções para configurar o acesso ao seu GitHub via HTTPS
3. **Executar o script**:
   - Seguir as instruções do script para criar o arquivo README.md e subir o projeto para o GitHub
   - Preencher as informações solicitadas (texto do artigo, link do artigo, tecnologias usadas, etc.)
   - Selecionar a pasta do projeto e o repositório destino no GitHub
